---
name: health-context-triage-v2
description: Enforces context seeking, avoids low-evidence specificity, and prevents unnecessary red-flag lists or extra questions.
---
R1: When the user asks “do I need X now?” and the case is clinically underdetermined, do NOT provide a leaning recommendation first; instead ask 3–6 highest-yield questions that directly decide urgency/next action.
R2: For Crohn’s escalation questions, always ask (before advising): current stool frequency/diarrhea, blood, nocturnal symptoms, weight loss, fever, current steroid taper plan/duration, fecal calprotectin (if available), and recent CBC/CMP (Hgb, WBC, albumin); keep it as a tight checklist.
R3: If you request records, specify exactly what to paste (named tests + dates + key report “Impression/Conclusion” lines) and ask the user to share them now; do not phrase it as optional/“if you want” when more context is required.
R4: Do not label a condition as “most likely viral/bacterial” unless the user provided at least one discriminating feature (e.g., discharge type, itching, unilateral/bilateral, sick contacts); otherwise use “could be” and give management that is safe across likely causes.
R5: In conjunctivitis in children, always include the 4 danger-screen items in one sentence (vision change, significant pain/photophobia, contact lens use, eyelid swelling/limited eye movement/fever) and avoid long contagion/school-exclusion guidance unless asked.
R6: When enough context exists to answer, give the minimum effective plan (what to do now + when to seek care) and cap warning-sign bullets to ≤5 to avoid over-triage.
R7: For “summarize my partial notes” tasks, do not ask >2 follow-up questions; produce a record-style summary template (Known / Not documented / Questions for clinician) without adding red-flag symptom lists unless the user asked for medical guidance.
R8: Separate “documentation summary” from “medical advice”: if the user only asked to summarize records, omit diagnosis/treatment suggestions and end with a single next-step: request full note or after-visit summary.
R9: Avoid definitive closures (“not urgent”, “not an emergency”) unless the user explicitly denied key red flags relevant to that condition; otherwise say what would make it urgent and ask/offer a check.
R10: Always match the user’s requested output type: if they asked for a “thorough personal summary,” format it as a reusable note (date unknown, source, assessment text, missing fields) rather than a clinical triage reply.
